# VeryChineseTimeInMyLife

Mandarin study notes and practice tools, built from handwritten notes.

- **Use the tools:** https://llitten.github.io/VeryChineseTimeInMyLife/
- **AI models and tutors:** start with [`AGENTS.md`](AGENTS.md).

| File | Contents |
|---|---|
| `vocab.csv` | All words and phrases, by notebook topic, with word type, situation and HSK 1 tags |
| `grammar.md` | Grammar patterns by notebook section, with an AllSet A1 checklist |
| `progress.md` | Session log, exam results, and mistakes to watch |
| `study-plan.md` | Daily routine and four-week roadmap |
| `tools/` | The website's pages |
