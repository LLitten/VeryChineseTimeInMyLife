Add 们 for more than one person: 我们, 你们, 他们.

Key words

我wǒ我ㄨㄛˇI, me
你nǐ你ㄋㄧˇyou
他tā他ㄊㄚhe
她tā她ㄊㄚsheSounds the same as 他; only the written character differs.
们men們˙ㄇㄣplural marker for peoplePlural for people: 我们, 你们, 他们.
我们wǒmen我們ㄨㄛˇ ˙ㄇㄣwe
她们tāmen她們ㄊㄚ ˙ㄇㄣthey (female)
这zhè這ㄓㄜˋthiszhè; often zhèi before a measure word: 这个.
那nà那ㄋㄚˋthatnà; often nèi before a measure word: 那个.

Examples

  • 我们是朋友。wǒmen shì péngyou.We're friends.
  • 这是我的，那是你的。zhè shì wǒ de, nà shì nǐ de.This is mine; that's yours.

Notes

  • 他 and 她 sound the same: tā.
  • 这 = this, 那 = that. Before a measure word: 这个, 那本.

Practice

They're students.他们是学生。tāmen shì xuésheng.Say it, then tap to check
