Verbs and helping verbs

Helping verbs go before the main verb to add meaning: want, can, may, have to. This page also covers 让 (let, make), 去 for going places, and 叫 and 姓 for names.

1. Want: 要, 想, 喜欢

Level
A1 #27
Keywords
想、要、喜欢

要 = want to. It can sound firm, like a plan.

Structure Examples Notes Practice Sources

Structure

Subject + 要 / 想 / 喜欢 + verb

Examples

  • 我要喝水。wǒ yào hē shuǐ.I want water.
  • 我想买水。wǒ xiǎng mǎi shuǐ.I'd like to buy water.
  • 我喜欢吃饭。wǒ xǐhuan chīfàn.I like eating.

Notes

  • 想 = would like to. Softer, and negated with 不想.
  • 喜欢 + verb = like doing.

Practice

What do you want to eat?你要吃什么？nǐ yào chī shénme?Say it, then tap to check

  • AllSet: Expressing "would like to" with "xiang"

2. Going to: 要

Level
A1 #25
Keywords
要

For plans you expect to carry out.

Structure Examples Notes Practice Sources

Structure

Subject + time + 要 + verb

Examples

  • 我明天要去北京。wǒ míngtiān yào qù Běijīng.I'm going to Beijing tomorrow.
  • 他就要来了。tā jiù yào lái le.He's about to arrive.

Notes

  • Use a time word, or 要 may sound like "want."
  • Don't use 在 for the future. 在 + verb means right now.

Practice

I'm going to buy a phone tomorrow.我明天要买手机。wǒ míngtiān yào mǎi shǒujī.Say it, then tap to check

Sources

  • AllSet: Expressing "be going to" with "yao"

3. Can: 会 and 能

Level
A1 #24 · #23
Keywords
会、能

会 = a learned skill: languages, driving, cooking. 不会 = don't know how.

Structure Examples Notes Practice Sources

Structure

Subject + 会 / 能 + verb

Examples

  • 我会说中文。wǒ huì shuō Zhōngwén.I can speak Chinese.
  • 我会画画。wǒ huì huàhuà.I can draw.your notes
  • 我能问你一个问题吗？wǒ néng wèn nǐ yí ge wèntí ma?Could I ask you a question?AllSet

Notes

  • 会 also means "will": 明天会很好.
  • 能 = able to, when circumstances allow. Also for polite requests: 我能…吗？

Practice

Can you speak English?你会说英语吗？nǐ huì shuō Yīngyǔ ma?Say it, then tap to check

Sources

  • AllSet: Expressing a learned skill with "hui"
  • AllSet: Expressing ability or possibility with "neng"

4. May: 可以

Level
A1 #26
Keywords
可以

Permission, like "may."

Structure Examples Notes Practice Sources

Structure

Subject + 可以 + verb

Examples

  • 我可以坐这儿吗？ 可以。wǒ kěyǐ zuò zhèr ma? kěyǐ.May I sit here? Sure.
  • 这里不可以吃东西。zhèlǐ bù kěyǐ chī dōngxi.No eating here.

Notes

  • 不可以 = not allowed.

Practice

5. Have to: 得 · Don't need to: 不用

Level
B1
Keywords
得、不用

得 here is said děi and means "have to."

Structure Examples Notes Practice Sources

Structure

Subject + 得 + verb · Subject + 不用 + verb

Examples

  • 我们得走了。wǒmen děi zǒu le.We have to go.AllSet
  • 你不用来。nǐ búyòng lái.You don't need to come.

Notes

  • "Don't need to" is 不用, not 不得 and not 不要.

Practice

I have to work.我得工作。wǒ děi gōngzuò.Say it, then tap to check

6. Let or make someone: 让

Level
B1
Keywords
让

让 = let, make, or ask someone to.

Structure Examples Notes Practice Sources

Structure

Subject + 让 + person + verb

Examples

  • 他让我睡觉。tā ràng wǒ shuìjiào.He lets me sleep.
  • 你让我很高兴。nǐ ràng wǒ hěn gāoxìng.You make me happy.
  • 你为什么不让我去？nǐ wèishénme bú ràng wǒ qù?Why won't you let me go?AllSet

Notes

  • 想让 = want someone to: 我想让你学习.

Practice

I want you to come.我想让你来。wǒ xiǎng ràng nǐ lái.Say it, then tap to check

7. Going places: 去

Level
A1 #21
Keywords
去

No word for "to": 我去学校.

Structure Examples Notes Practice Sources

Structure

Subject + 去 + place · Subject + 去 + verb

Examples

  • 我明天去学校。wǒ míngtiān qù xuéxiào.I'm going to school tomorrow.
  • 我去买东西。wǒ qù mǎi dōngxi.I'm going shopping.

Notes

  • No 在 after 去.
  • 去 + verb = go to do something: 我去买东西.

Practice

I'm going to the bank.我去银行。wǒ qù yínháng.Say it, then tap to check

Sources

8. Names: 叫 and 姓

Level
A1 #20 · #22
Keywords
叫、姓

叫 = to be called. Works for people, pets and places.

Structure Examples Notes Practice Sources

Structure

Subject + 叫 + name · Subject + 姓 + surname

Examples

  • 我叫安娜。你叫什么名字？wǒ jiào Ānnà. nǐ jiào shénme míngzi?I'm Anna. What's your name?
  • 我姓王。wǒ xìng Wáng.My surname is Wang.

Notes

  • 姓 = surname. The polite question is 您贵姓？

Practice

What's your name?你叫什么名字？nǐ jiào shénme míngzi?Say it, then tap to check

Sources

  • AllSet: Using the verb "jiao"
